# Petday 宠物陪伴微信小程序

Petday 是一款以数字猫咪“奶盖”为核心的宠物陪伴微信小程序。界面采用圆润、轻盈的校园青春风格，配合玻璃质感卡片、移动端安全区适配和猫咪互动动画。

## 功能

- 喂食、玩耍、抱抱等日常陪伴互动
- 点击猫咪、舔爪与碰爪反馈动画
- 饱食、心情、活力和亲密度状态
- 每日签到、连续陪伴和成长经验
- 陪伴日记与校园活动
- 本地数据持久化，无需后端即可体验
- Android 与 iOS 安全区及多尺寸屏幕适配

## 本地运行

1. 安装微信开发者工具。
2. 选择“导入项目”，打开本仓库根目录。
3. 在 `project.config.json` 中将 `appid` 替换为你自己的小程序 AppID；仅本地体验也可使用测试号。
4. 编译并在模拟器或真机中预览。

## 项目结构

```text
assets/             猫咪互动图片与动画资源
pages/index/        首页和猫咪互动
pages/diary/        陪伴日记
pages/activities/   校园活动
pages/profile/      个人中心
styles/             跨页面移动端适配样式
utils/pet.js        本地状态与成长逻辑
```

## 数据说明

当前版本使用微信小程序本地存储保存宠物状态、日记和签到记录。清除小程序缓存会重置这些数据。

## 说明

仓库不包含微信开发者工具生成的 `project.private.config.json`。发布或上线前，请根据自己的账号、隐私政策和服务类目完成微信公众平台配置与审核。
